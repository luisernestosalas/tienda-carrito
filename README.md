# 🛒 Tienda con Carrito

Una aplicación web de tienda en línea con funcionalidad de carrito de compras, desarrollada con tecnologías web fundamentales.

## 🌐 Demo en Vivo

Puedes ver la aplicación funcionando en: [tienda-carrito-krko6h46g-luisernestosalas-2775s-projects.vercel.app](https://tienda-carrito-krko6h46g-luisernestosalas-2775s-projects.vercel.app)

## ✨ Características

- 📦 Catálogo de productos interactivo
- 🛍️ Carrito de compras funcional
- ➕ Agregar y remover productos del carrito
- 💰 Cálculo automático del total
- 📱 Diseño responsivo
- 🎨 Interfaz de usuario intuitiva
- 🚀 Carga rápida y rendimiento optimizado

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura y marcado semántico
- **CSS3** - Estilos y diseño responsivo
